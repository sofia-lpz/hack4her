# hack4her

This is the second place project at Hack4Her, the first all women hackathon in Mexico

We built an AI-powered mobile app for Arca collaborators to rate and review stores, schedule appointments, and view store info on an interactive map. We also integrated AI-generated summaries of store reviews and a natural language chatbot with a specialized architecture to answer questions about the data.

I'm very proud of what we achieved in such a short time and of participating in such an amazing event. In most hackathons I’ve attended, I’ve been one of the only women coding through the night, so it felt surreal to be surrounded at this event by so many incredible women!

See you next year!
